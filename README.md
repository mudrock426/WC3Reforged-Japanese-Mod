# Company of Heroes 2 日本語化 MOD（非公式）

Company of Heroes 2（Steam／Windows 64-bit版）向けの**非公式・ファンメイド**の日本語化パッチャーです。  
利用者の PC にインストールされている正規のゲームデータを使い、英語の表示テキストを日本語に置き換え、日本語フォントを表示できるようにします。

> [!IMPORTANT]
> 本プロジェクトは Relic Entertainment および SEGA とは一切関係のない非公式プロジェクトです。  
> 配布物には、ゲーム本体の実行ファイル・原文テキストファイル（`.ucs`）・アーカイブ（`.sga`）・音声・映像などの**ゲーム原本ファイルは含まれていません**。配布するのは日本語訳データ、自作パッチャー、自作プロキシ DLL、日本語フォント用データなどです。

> [!WARNING]
> **本 MOD は `d3dcompiler_46.dll` という自作プロキシ DLL を導入し、ゲーム実行中のメモリ上の処理を一部変更します。** ゲーム本体の `RelicCoH2.exe` は書き換えませんが、対応しないゲームバージョンでは起動失敗・クラッシュの可能性があります。  
> **オンライン対戦・アンチチートへの影響は未検証です。オンラインでの使用は自己責任です。**

## 動作要件

- **Company of Heroes 2**（Steam版・64-bit）
- **Windows 10 / 11（64-bit）**
- **Steam のゲーム言語設定を「English」にすること**  
  英語用の `RelicCoH2.English.ucs` を日本語に置き換える仕組みです。
- **Python 3.10 以上**  
  [公式サイト](https://www.python.org/downloads/) からインストールしてください。インストール時は `Add Python to PATH` を有効にしてください。
- **ゲームフォルダ内の `Archive.exe`・`UIHigh.sga`・元の `d3dcompiler_46.dll` が必要です。**

**DLLの互換性について：** 開発時に参照した `warnings.log` のビルド識別表示は `exe 0x00005f10:data 0x0e2b5016` です。ただし、この表示が一致しても安全性や動作を保証するものではありません。ゲームの更新後や別ビルドでの動作は未確認です。

## インストール方法

1. Steamで Company of Heroes 2 の言語を **English** に設定します。
2. [Releases ページ](../../releases) から最新の `CoH2_Japanese_Mod_v1.0.zip` をダウンロードし、任意のフォルダに**すべて展開**します。
3. **Company of Heroes 2 を完全に終了した状態で**、`install_ja.bat` をダブルクリックして実行します。
   - ゲームのインストール先は自動検出を試みます。見つからない場合はフォルダのパスを入力してください。
4. 完了メッセージを確認し、**まずオフラインのキャンペーンで**日本語表示を確認してください。

> [!NOTE]
> GitHubの **Code → Download ZIP** は開発用ファイル一式です。通常の導入には **Releasesに添付された配布ZIP** を使用してください。

### アップデート方法

新しい配布ZIPを展開し、ゲームを終了してから `install_ja.bat` を再実行します。既存の導入記録を利用して更新する設計です。  
**古いバックアップフォルダや導入記録を手動で削除しないでください。** ゲーム本体が更新された直後は、MOD側の対応を確認するまで導入・更新を控えてください。

## アンインストール方法（元に戻す）

1. Company of Heroes 2 を完全に終了します。
2. `uninstall_ja.bat` をダブルクリックして実行します。
   - MODの追加ファイルを削除し、バックアップした元の `.ucs` と DLL などを復元する設計です。
3. 元の英語版で起動することを確認してください。

エラーが発生した場合は、**バックアップ・導入記録・一時ファイルを自分で削除せず**、表示された内容を確認してください。ゲームフォルダの移動、バックアップの欠損、他MODとの競合がある場合は、完全に復元できない可能性があります。

## 本 MOD が PC に対して行う変更

処理内容を確認できるよう、パッチャー（`patcher.py`）とプロキシ DLL のC++ソース（`src/d3dcompiler_46_proxy.cpp`）を公開しています。

| 対象 | 内容 |
|---|---|
| `CoH2\Locale\English\RelicCoH2.English.ucs` | 既存の文字列IDを保ち、日本語訳を適用したファイルに差し替えます（元ファイルはバックアップ） |
| `CoH2\Archives\UIHigh.sga` | **読み取りのみ**。同梱の `Archive.exe` を使って必要なUIデータを取り出します |
| ゲームフォルダ直下の `coh2ui_redir.gfx` | 日本語フォント対応のUIデータを利用者のPC上で生成・配置します |
| ゲームフォルダ直下の `d3dcompiler_46.dll` | 自作64-bitプロキシDLLを配置。元DLLは `d3dcompiler_46_orig.dll` として転送処理に利用します |
| 実行中のゲームメモリ | フォント用UIの読み込み処理をフックします。**`RelicCoH2.exe` 自体は変更しません** |
| ゲームフォルダ直下の `.coh2_ja_backup` | MOD導入前の既存ファイルをバックアップします |
| ゲームフォルダ直下の `coh2_ja_manifest.json` | 導入ファイルと復元対象の記録です |
| 作業中の一時ファイル | `coh2_ja_journal.json` と `.coh2_ja_tx_backup` は中断時の復旧に使用します。**手動で削除しないでください** |

- パッチャー自身は、ゲーム外のサーバーへ翻訳データや利用者情報を送信する処理を実装していません。
- ゲームの `.sga` 原本を上書きする処理はありません。
- ゲームフォルダへの書き込み権限が必要です。インストール先の権限設定によっては実行が制限されます。

### プロキシ DLL の制約と確認方法

DLLは `RelicCoH2.exe` の**固定オフセット**を参照し、想定する命令列かどうかを照合してから処理を変更します。ただし、参照先のメモリ範囲を十分に検証する設計ではなく、**対応外バージョンで必ず安全にスキップするとは限りません**。長時間動作時のストリーム管理も、すべての環境で検証済みではありません。

- 配布DLL：`bin/d3dcompiler_46.dll`
- C++ソース：`src/d3dcompiler_46_proxy.cpp`
- SHA-256：`ae60b1c1c95b77426be3f2256785949a8c466c7bc98108420ad094b8ecfe3b7f`
- 他のファイルのハッシュ：[`CHECKSUMS.sha256`](CHECKSUMS.sha256)

Visual Studio 2022の **x64 Native Tools Command Prompt** でのビルド例：

```bat
cl /nologo /O2 /LD src\d3dcompiler_46_proxy.cpp /Fe:bin\d3dcompiler_46.dll
```

ハッシュとソースの公開は確認材料であり、安全性の証明ではありません。ビルド環境によって再ビルド結果のバイナリが完全一致しないことがあります。

## よくある質問

**Q. ウイルス対策ソフトに警告されました。**  
A. 実行時に読み込まれるプロキシDLLやメモリ変更処理が警戒される可能性があります。**ゲームフォルダ全体をウイルス対策の除外対象にしないでください。** DLLのソース・ハッシュを確認し、不審な警告がある場合は導入を中止してください。

**Q. オンライン対戦で使用できますか？**  
A. **推奨しません。** オンライン対戦・アンチチート・アカウントへの影響は検証していません。日本語表示を目的としたMODですが、実行中のメモリ処理を変更するため、問題が起きないと保証できません。

**Q. 一部が英語のまま表示されます。**  
A. 翻訳データにない文字列、ゲーム更新で追加された文字列、音声などは日本語化されません。誤訳・表示崩れも残っている可能性があります。

**Q. タイトル画面で止まり、音だけが鳴ります。**  
A. まずMODをアンインストールし、ゲーム単体でも再現するか確認してください。高リフレッシュレート環境で問題が起きる場合は、Steamの起動オプションとして次を試す報告もありますが、効果は保証しません。

```text
-refresh 60 -nomovies -window -fullwindow
```

**Q. `Archive.exe` または `UIHigh.sga` が見つからないと言われます。**  
A. ゲームのインストール先と言語設定を確認してください。これらのファイルは配布ZIPに含めていません。ゲーム本体のファイルを他サイトから取得することは案内していません。

**Q. 他のMODと併用できますか？**  
A. 同じ `.ucs` やDLLを変更するMODとは競合する場合があります。既存ファイルはバックアップしますが、**併用時の正常動作や完全復元は保証していません。**

## 翻訳について

翻訳はAIを活用して作成し、原文との照合、兵器・部隊名の用語統一、人物の口調の調整、誤訳修正、形式チェックを行っています。ただし、誤訳や不自然な表現が残っている可能性があります。

### 主な軍事用語の表記例

| 英語 | 本MODで使用している日本語表記例 |
|---|---|
| Conscripts | 徴集兵（分隊名では「徴集兵分隊」） |
| Panzer IV | IV号戦車 |
| Panther | パンター |
| Tiger | ティーガー |

※ 文章の文脈やユニットの正式名称によって、追加の語句や型式を付ける場合があります。

誤訳の指摘や、より自然な訳の提案は、[Issues](../../issues) からお知らせください。  
**該当するゲームモード・場面、表示されている日本語、可能であれば文字列ID**を添えていただけると修正に役立ちます。ログを添付する場合は、ユーザー名・アカウント情報・ローカルパスなどの個人情報を削除してください。
