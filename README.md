# Warcraft III: Reforged 日本語化 MOD（非公式）

Warcraft III: Reforged（Windows版）向けの**非公式・ファンメイド**の日本語化パッチャーです。  
利用者の PC にインストールされている正規のゲームデータ（CASC）を読み取り、日本語訳テキストと日本語フォントを適用します。

> [!IMPORTANT]
> 本プロジェクトは Blizzard Entertainment, Inc. とは一切関係のない非公式プロジェクトです。  
> 本リポジトリおよび配布物には、ゲーム本体のデータ（マップ・原文テキスト・音声・映像・画像・Blizzard 製フォント等）は含まれていません。配布しているのは、ファンによる日本語訳テキストとパッチャーのみです。

## 動作要件

- **Warcraft III: Reforged**（Windows版）
- **Battle.net のゲーム言語設定を「韓国語（한국어）」にすること**  
  本 MOD は韓国語リソースを日本語に置き換えて動作します。
- **Python 3.10 以上**  
  [公式サイト](https://www.python.org/downloads/) からインストールしてください。インストール時に「Add Python to PATH」にチェックを入れてください。

---

## インストール方法

1. [Releases ページ](../../releases) から最新の `WC3Reforged_JP_Mod.zip` をダウンロードします。
2. ZIP ファイルを任意のフォルダに展開（解凍）します。
3. **Warcraft III を完全に終了した状態で**、`install_ja.bat` をダブルクリックして実行します。
   - Warcraft III のインストール先は自動で検出されます。見つからない場合はフォルダのパスを入力してください。
4. 完了メッセージが表示されたら、Warcraft III を起動してください。

### アップデート方法

新しい ZIP を展開して、`install_ja.bat` をもう一度実行するだけで上書き更新できます。  
（古いバージョンで導入され、不要になったファイルは自動で削除されます）

---

## アンインストール方法（元に戻す）

1. Warcraft III を完全に終了します。
2. `uninstall_ja.bat` をダブルクリックして実行します。
   - 本 MOD が導入したファイルを削除し、上書き前のファイルとレジストリ設定を元の状態に戻します。

## 本 MOD が PC に対して行う変更

安心してお使いいただけるよう、変更内容をすべて記載します。ソースコード（`patcher.py` など）もすべて公開しています。

| 対象 | 内容 |
|---|---|
| レジストリ | `HKEY_CURRENT_USER\Software\Blizzard Entertainment\Warcraft III` の `Allow Local Files` を `1` に設定（アンインストール時に元の値へ戻します） |
| ゲームフォルダ | `Warcraft III\_retail_\` 以下に日本語化ファイルとフォントを配置 |
| バックアップ | 既存ファイルを上書きする場合は `_retail_\.wc3_ja_backup\` に退避 |
| 導入記録 | `_retail_\wc3_ja_manifest.json`（アンインストール用の記録） |
| 作業中の一時ファイル | `_retail_\wc3_ja_journal.json`（作業記録）と `_retail_\.wc3_ja_tx_backup\`（更新時の一時バックアップ）。処理が正常に終わると自動で削除されます。途中で電源が落ちた場合などは、次回の実行時にこれらを使って元の状態に戻すため、手動で削除しないでください |

- インターネット通信は一切行いません。
- ゲーム本体のアーカイブ（`Data` フォルダ）は読み取るだけで、変更しません。
- 管理者権限は必要ありません（ゲームを `Program Files` 配下にインストールしている場合は、書き込み権限の関係で管理者として実行が必要になることがあります）。

## よくある質問

**Q. ウイルス対策ソフトに警告されました。**  
A. `.bat` ファイルからスクリプトを実行し、レジストリを変更するため、警告が出る場合があります。処理内容は上の表のとおりで、ソースコードもすべて公開しています。ご不安な場合は、ソースをご確認のうえでご利用ください。

**Q. オンライン対戦で使っても大丈夫ですか？**  
A. 本 MOD は日本語表示を目的としたもので、ゲームバランスやユニットの性能は変更しません。

変更するのは主に表示テキストとフォントです。ただし、キャンペーンをステージクリア後に正しく日本語版で続けられるよう、**キャンペーンマップについては、日本語化したマップを別の場所に配置し、マップ内で次のステージを読み込む参照先を書き換えています。** 対戦用マップは変更しません。

なお、オンライン環境での動作やアカウントへの影響については検証・保証していません。ご自身の判断でご利用ください。

**Q. 一部が韓国語のまま表示されます。**  
A. 本 MOD は韓国語設定のゲームを日本語に置き換える仕組みのため、次の箇所は仕様上韓国語のまま表示されます。

- **セーブデータの日付表示**（例: `2026.11.17. 오후 9:52`）  
  日付の形式はゲーム本体が生成しているため、MOD 側では変更できません。`오전` は「午前」、`오후` は「午後」という意味です。
- **未翻訳の箇所**（汎用ボイスの字幕など一部）
- **新キャンペーン DLC「Forsaken Kingdom」**（現時点では翻訳対象外です）

**Q. キャンペーンが Definitive Edition の画質になりません。**  
A. 2026年11月時点では、オプションで Definitive Edition を選んでも、本編キャンペーン（Reign of Chaos / The Frozen Throne）は Definitive Edition の画質になりません。これは **MOD の有無にかかわらず起きる、ゲーム本体側の挙動**です（対戦モードでは Definitive Edition の画質になります）。今後のゲームのアップデートで変わる可能性があります。

**Q. `fonts` フォルダに `FRIZQT__.TTF` があるのはなぜですか？**  
A. 中身は **Noto Sans JP**（オープンソースフォント）です。ゲームがこのファイル名でフォントを参照するため、ファイル名だけを変更して同梱しています。Blizzard 製のフォントではありません。

## 翻訳について

翻訳は AI 翻訳をベースにしており、原文との照合・固有名詞の統一・誤訳修正などのチェックを行っています。ただし、不自然な表現・誤訳・表記ゆれが残っている可能性があります。

### 固有名詞の表記

人名・地名などの固有名詞は、他の Blizzard 作品の日本語版で定着している表記に合わせ、全編で統一しています。主な表記は次のとおりです。

| 英語 | 本 MOD での表記 |
|---|---|
| Arthas | アーサス |
| Thrall | スロール |
| Jaina | ジェイナ |
| Uther | ウーサー |
| Illidan | イリダン |
| Sylvanas | シルヴァナス |
| Lich King | リッチキング |
| Lordaeron | ローデロン |
| Scourge | スコージ |
| Burning Legion | バーニング・レギオン |
| Frostmourne | フロストモーン |

誤訳の指摘や、より良い訳の提案を歓迎します。[Issues](../../issues) またはプルリクエストでお知らせください。  
その際は、**該当する場面（キャンペーン名・ミッション名など）と現在の訳文**を書いていただけると助かります。
